## 10 review passes

Each pass = build + screenshot + edit + rebuild. Each dispatches the team (brand-identity, typography-architect, feature-illustrator, form-redesign, integration-lead) and the orchestrator decides which fixes to apply.

1. **Visual hierarchy** — does the 2:1 split read correctly on `/signup`? Is the Fraunces wordmark balanced with the indigo CTA?
2. **Type rhythm** — Fraunces vs Raleway vs Montserrat contrast; letter-spacing at the largest h1; line lengths.
3. **SVG clarity** — Trail pipeline reads at first glance? Approval hold-progress bar feels like 3 seconds?
4. **Form interaction** — password meter jumps correctly? Email blur validation preserved? Tab order correct? Indigo focus state visible?
5. **Navbar** — Fraunces wordmark, 4 product links, sticky with backdrop blur, indigo hover state.
6. **Light-mode default** — fix the themeBootstrap so OS preference is honored when localStorage is empty. Confirm dark-mode toggle works and persists.
7. **Mobile** — 375px and 320px breakpoints for `/` (landing) and `/signup` (signup).
8. **A11y** — focus rings on every interactive; form labels associated; SVGs have aria-hidden/title; reduced-motion respected; forced-colors handled.
9. **Cross-route regression** — landing → click "Sign in" → click "Create one" → confirm visual continuity (Fraunces wordmark in navbar, same kicker style, same indigo accent in CTAs).
10. **Polish** — hover timings, button spinner alignment, kicker dot color, eyebrow weight, password strength thresholds, logo optical alignment.

Each pass produces screenshots. Orchestrator applies fixes; team agents fix.
