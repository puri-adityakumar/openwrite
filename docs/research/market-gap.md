# Market Gap (tool complaint mining — Aug 2026)

**#1 cross-tool complaint:** hallucinated summaries with no way to verify them.
Elicit, SciSpace, Undermind, ChatPDF, NotebookLM all hit this.

## Feature audit vs. existing tools

| Feature | Status in market |
|---|---|
| (a) Dashboard view | **partial** (Elicit extraction table, SciSpace literature-review panels — none combines graph+table+chat in one workspace) |
| (b) Mode/purpose selection ("reading to learn" vs "reviewing" vs "citing") | **NONE FOUND anywhere** |
| (c) Integrated paper stats (downloads/views) | **NONE FOUND** (citations only via S2, Connected Papers, Litmaps; no AI-analysis tool overlays readership stats) |
| (d) Author profiling inside reading flow | **NONE FOUND** |
| (e) Inline annotation + side chat | **partial** (Zotero+GPT plugin fragile; SciSpace highlight-to-explain) |

## Demand quotes

- "I wish there was something similar [to arxiv-sanity] for the general literature"
- "Wish there was a way to consume papers with less friction"
- NotebookLM-for-papers gap: "the two-person podcast format is kind of annoying and it can't pronounce math."

**Conclusion:** our feature set (b)–(e) is unoccupied. This is the defensible
whitespace; the Verify gate answers the #1 complaint.
